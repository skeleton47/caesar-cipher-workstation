How the Caesar Cipher Works

The foundations of monoalphabetic substitution cryptography.

∑

Modular Arithmetic

Each letter is mapped to an integer (A=0, B=1, ... Z=25). Encryption shifts every character forward along the cyclic group modulo 26:

C ≡ (P + K) mod 26
⚡

Trivial Key Space

Because English has only 26 letters, there are only 25 non-trivial shifts. A modern computer can test every single key in less than a fraction of a millisecond.

|K| = 25 keys ≈ 4.64 bits
📊

Frequency Invariance

A simple shift preserves letter frequency distribution. The most common letter in English (E at ~12.7%) simply shifts to another position, making manual frequency attacks immediate.

ETAOIN SHRDLU Heuristic
🛡️

Modern Cryptography

Caesar is an educational foundation. Real-world systems use authenticated ciphers like AES-256-GCM or ChaCha20-Poly1305 with 256-bit entropy keys ($2^{256}$ states).
