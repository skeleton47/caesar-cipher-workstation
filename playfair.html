Rectangle Rule

If the two letters are in different rows and columns, form a rectangle. Replace each letter with the letter in its own row and the other letter's column.

(r1, c1) & (r2, c2) → (r1, c2) & (r2, c1)
2

Same Row Rule

If both letters are in the same row, shift each one position to the right (wrap to start on overflow). For decryption, shift left.

Shift: (col + 1) mod 5
3

Same Column Rule

If both letters are in the same column, shift each one position down (wrap to top on overflow). For decryption, shift up.

Shift: (row + 1) mod 5
