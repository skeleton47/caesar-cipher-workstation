MIL-SPEC CR-26.4

Formal mathematical formulation, complexity bounds, and vulnerability profiles

01 // Caesar Cipher (ROT-N)

Monoalphabetic
C ≡ (P + K) mod 26
P ≡ (C - K) mod 26

Substitution mapping where every glyph is shifted by a constant integer K in the cyclic finite group ℤ₂₆. Keyspace is limited to 25 non-trivial permutations, permitting instantaneous brute-force cracking (< 0.001ms).

02 // Vigenère Cipher

Polyalphabetic
Cᵢ ≡ (Pᵢ + Kᵢ) mod 26
where Kᵢ = Key[i mod L]

Employs a repeating periodic keystream vector across a Tabula Recta matrix. While flattening basic unigram frequency peaks, it remains vulnerable to Kasiski examination and Index of Coincidence (IoC) periodic factor attacks.

03 // Frequency Cryptanalysis

Heuristic
χ² = Σ [ (Oᵢ - Eᵢ)² / Eᵢ ]
IoC = Σ [ fᵢ(fᵢ - 1) / (N(N - 1)) ]

Uses the non-uniform natural distribution of standard English (ETAOIN SHRDLU: 'E' ≈ 12.7%, 'T' ≈ 9.1%) to identify cipher shifts without prior knowledge of the secret key.
