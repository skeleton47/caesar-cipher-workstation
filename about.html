Formal mathematical foundations, keyspace complexity bounds, and vulnerability profiles

01 // Caesar Cipher

Monoalphabetic
C ≡ (P + K) mod 26
P ≡ (C - K) mod 26

Cyclic permutation over the finite group ℤ₂₆ with an invariant shift K. The keyspace is strictly limited to 25 non-trivial shifts, permitting instantaneous exhaustive brute-force cryptanalysis (< 0.001ms).

Keyspace: 25 keys Broken: O(26)

02 // Vigenère Cipher

Polyalphabetic
Cᵢ ≡ (Pᵢ + K[i mod L]) mod 26
Pᵢ ≡ (Cᵢ - K[i mod L]) mod 26

Superimposes a periodic keystream of length L across a 26×26 Tabula Recta. While masking unigram frequencies, it yields to Kasiski examination for period deduction and Index of Coincidence factor attacks.

Keyspace: 26ᴸ states Kasiski / IoC

03 // Playfair Cipher

Digraph Substitution
5×5 Grid (I/J Merged)
Row / Col / Rectangle Shift

First practical digraph substitution cipher (Wheatstone, 1854). Encrypts pairs across a 25-letter matrix (600 digraph states). Defeats single-letter frequency attacks, but succumbs to digraph frequency analysis.

Pairs: 25×24 = 600 Known-Digraph

04 // Hill Cipher

Modular Linear Algebra
c ≡ K · p (mod 26)
p ≡ K⁻¹ · c (mod 26)

Polygraphic cipher based on modular matrix-vector multiplication (Lester S. Hill, 1929). Invertibility strictly requires gcd(det(K), 26) = 1. Vulnerable to Known-Plaintext Attacks: intercepting n independent vectors yields K = C · P⁻¹.

Condition: gcd(det,26)=1 Linear KPA

05 // Frequency Analysis

Statistical Heuristic
χ² = Σ [ (Oᵢ - Eᵢ)² / Eᵢ ]
IoC = Σ [ fᵢ(fᵢ - 1) / (N(N - 1)) ]

Exploits non-uniform unigram distribution in English (ETAOIN SHRDLU: 'E' ≈ 12.7%, 'T' ≈ 9.1%). Automates candidate scoring and distinguishes between monoalphabetic and polyalphabetic cipher payloads.

Baseline: English ETAOIN Chi-Square Test
